# tests

Unit tests of the pipeline's functions, run by hand.
No script or phase calls them, and nothing in `src/` or `scripts/` depends on this folder.
Every suite uses synthetic inputs and reads neither `data/` nor `results/`; `autocorrelationTimescaleTest`, which runs Phase 6 end to end, and `atomicFileWritersTest` write only to temporary folders.

## Running them

From the repository root:

```bash
matlab -batch "addpath(genpath('src')); r = runtests('tests'); disp(table(r))"
```

Each suite also puts `src/` on the path itself, so a single file runs on its own, for example `runtests('tests/tFitDomainTest.m')`.

The Python oracles in `oracles/` carry PEP 723 headers and run under `uv`, also from the repository root:

```bash
uv run tests/oracles/<script>.py
```

## What is here

| Suite                                   | What it checks                                                                                                                                                                                                                                                                                                                            |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tCopulaKernelTest`                     | the six t-copula kernels and `informationMeasuresT`: the tail quantile against `tinv` and closed forms, the log-likelihood against an independent copy of the density, `kappa_t` against the mpmath oracle, and the sampler's dependence and margins                                                                                      |
| `tCopulaFitTest`                        | `fitTCopulaShape` and `tFitDefaultOptions`: shape recovery, the Gaussian lower bound and its snap rule, a heavy-tailed optimum inside the domain, the ambiguity flag and the option validator                                                                                                                                             |
| `tFitDomainTest`                        | the shape domain `p` in `[0, 3]`: truths at nu = 0.5 and nu = 1/3 recovered, the `heavy_boundary` flag, and a numerically sound fit at a Gaussian truth                                                                                                                                                                                   |
| `tCopulaQuantileCacheTest`              | the quantile cache is exact: cached and direct log-likelihoods agree bit for bit, and the fit is the same with and without it                                                                                                                                                                                                             |
| `unitFitTest`                           | the unit row: `tFitChannelSet` equals `unitCorrelationFromTau` followed by `tFitUnit`, and the field set is identical across dimensions and error paths                                                                                                                                                                                   |
| `unitRowsToColumnsTest`                 | the column layout of unit rows in MAT files: an exact round trip through `unitRowsToColumns` and `unitColumnsToRows` over an error path with NaNs, the declared shapes and codes, index selection, the empty case, and the same table from either layout                                                                                  |
| `tCopulaSampleRadialTest`               | the sampler's radial law: the Mahalanobis form follows `F(d, nu)`, and `chi2(d)/d` at the Gaussian point                                                                                                                                                                                                                                  |
| `copulaDensityGridTest`                 | the model density panels of Phase 5: total mass 1, uniform margins, the cell average against the density kernel, and `p = 0` delegated to the Gaussian copula                                                                                                                                                                             |
| `computePairEmpiricalCopulaDensityTest` | the empirical panel of Phase 5 is a cell-averaged density that integrates to 1 on uniform and ragged grids, is close to 1 everywhere for independent data, and refuses a grid that does not span the unit square                                                                                                                          |
| `tInformationDifferencesTest`           | the closed-form t-minus-Gaussian differences: exactly zero at `p = 0`, the entropy identities, agreement with `informationMeasuresT`, and the second-order approach to the Gaussian point                                                                                                                                                 |
| `tInformationMeasuresFromLogdetsTest`   | the log-determinant route of Phase 4 (`tInformationMeasuresFromLogdets`) agrees with `informationMeasuresT` to 1e-10 on random units and carries the same percentage policy                                                                                                                                                               |
| `coherentPhaseSurrogateTest`            | the surrogate generator: real output, periodograms, cross-spectra and column means preserved, no row mixed across a segment boundary, and seed reproducibility                                                                                                                                                                            |
| `distributionOverlapTest`               | the overlap coefficient of Phase 3: 1 for identical and 0 for disjoint samples, the atoms at `p = 0` and `p = 3` as cells of their own, invariance under a strictly increasing map, one-value samples, unequal sizes, and empty and non-finite input                                                                                      |
| `summarizeSurrogateComparisonTest`      | the observed-versus-surrogate comparison of Phase 3: deterministic balanced halves, dimensions with one to three channel sets, failed fits excluded and counted, the overlap columns, floors per dimension and realization with MI only at `d = 2`, and the column names                                                                  |
| `kendallTauMatrixParallelTest`          | `kendallTauMatrixParallel` equals `kendallTauMatrix` bit for bit, with ties, at one pair, with a constant column and under a worker limit, and a zero-worker request opens no pool                                                                                                                                                        |
| `autocorrelationTimescaleTest`          | the time-scale estimator of Phases 6 and 7: the known time scales of an AR(1) and of a damped oscillation, segment handling under both centrings, the integrated amplitude excess and its Gaussian reference, named argument errors, and Phase 6 run end to end on a synthetic one-segment recording                                      |
| `studentDiffusionPathTest`              | the Metropolis-corrected Student diffusion: the Student radial law held at a coarse step where the uncorrected control chain loses it, the exact OU branch, nested rates read from one path bit for bit, the Gaussian branch drawn in blocks, seed reproducibility with the global generator untouched, orientation and input errors      |
| `simulationJobOrderTest`                | the jobs, cells and seeds of Phase 7 over the declared axes (p_true, T/tau, samples per tau): pilot subsets keep production numbers, seeds do not depend on `d` or the rate, a rate off the substep grid is refused, and the nested fits equal `tFitChannelSet` on the subset                                                             |
| `simulatorCheckSummariesTest`           | the simulator check's reading rules on synthetic jobs with known answers: KS distances against a Bonferroni level, the pooled refinement interval (plus or minus 1.96 standard errors) and the seeded bootstrap interval of the pooled sd ratio, the relaxation clock error and its bound on `p_hat`, and the integrated amplitude excess |
| `simulationInformationErrorTest`        | the error decomposition of the information measures in Phase 7 (the p-only, R-only and interaction parts add up to the whole error) and the summaries keyed on `T/tau` and samples per tau                                                                                                                                                |
| `tStudyHelpersTest`                     | `informationMeasuresT` with its percentage policy, `tCopulaTheoryGrid` and `studySeed`                                                                                                                                                                                                                                                    |
| `atomicFileWritersTest`                 | `saveStructAtomic` and `writeTableAtomic` stage through a name unique to the writer: no writer touches another's staging file, and a published file leaves nothing beside it                                                                                                                                                              |
| `settingsIdentityTest`                  | the settings identity hash: insensitive to field order and to a logical versus its 0/1, sensitive to every scientific field, different for an empty override and its defaults, and reaching into struct arrays                                                                                                                            |
